# Reference rig

Owner selection is pending. The planning baseline is an 8 GB or greater discrete GPU, or a comparable Apple Silicon Pro/Max machine, with WebGPU-capable Chromium. Acceptance is 2560 × 1440 output at 60 fps average and at least 45 fps 1% low in the 12 required golden shots. The release tests also require a physical webcam for the camera-to-intent latency measurement.

The Linux development environment exposes an Intel Core Ultra 3 205 and no hardware GPU device or webcam. Record its software adapter separately in each capture. It can verify WebGPU command execution and functional parity with the existing game.

Record the exact CPU, GPU, driver, VRAM or unified memory, browser version, OS, display refresh, input device, resolution, render scale, quality settings and power mode when the reference rig is available.
